# Project 01 – Employee Management System

Enterprise Employee Management System built using Spring Boot, REST APIs, Spring Data JPA, and MySQL.

---

## Overview

This project provides backend APIs for managing employee records in an enterprise environment.

Features:

- Create Employee
- View All Employees
- View Employee by ID
- Update Employee
- Delete Employee
- REST API Structure
- Database Integration
- Layered Architecture

---

## Business Scenario

Organizations need a centralized system to manage employee information such as:

- Employee ID
- Name
- Email
- Department
- Position
- Salary

This project demonstrates a clean enterprise backend structure using Spring Boot.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/employees` | Get all employees |
| GET | `/api/employees/{id}` | Get employee by ID |
| POST | `/api/employees` | Create employee |
| PUT | `/api/employees/{id}` | Update employee |
| DELETE | `/api/employees/{id}` | Delete employee |
